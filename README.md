## 🚀 Featured Work: The DevBurger Ecosystem

Rather than isolated projects, I build cohesive platforms. **DevBurger** is a complete, production-ready e-commerce architecture designed for digital delivery, split into a highly scalable API and a modern web client.

### 🍔 [DevBurger API (Backend)](https://github.com/eduardobm0708/devburguer-api-novo)
*Robust backend architecture handling product catalogs, secure payments, and order queues.*

* **Hybrid Database Architecture:** Engineered using **PostgreSQL** (ACID transactions for Users, Products, and Categories) and **MongoDB** (flexible document structure for fast order tracking and queues).
* **Business Logic & Security:** Implemented stateless Auth (JWT), role-based access control (Admin/Client), and secure password hashing (Bcrypt).
* **Payment Gateway:** Seamlessly integrated with **Stripe API** for secure PaymentIntent creation and transaction processing.

### 🍕 [DevBurger Web Client (Frontend)](https://github.com/eduardobm0708/devburger-frontEnd)
*Interactive digital menu and e-commerce client built for performance.*

* **State Management:** Utilized **React Context API** to handle complex cart logic, user sessions, and persistent local storage.
* **Modern UI/UX:** Styled completely from scratch using **Styled-Components**, ensuring a fully responsive and modular interface.
* **Performance:** Bundled with **Vite** for aggressive load times and optimized with **React Router** for fluid, SPA-like navigation.
